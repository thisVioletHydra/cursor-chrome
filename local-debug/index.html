local-debug

Заполни три поля и нажми «Проверить». Когда все три PASS, скачай конфиг. Он живёт 2 часа. На проде: главная админки → «Импорт» → выбери файл.

1. Telegram

ЖДЁТ

Открой Telegram → @BotFather → /mybots → свой бот → API Token. Скопируй токен целиком, он вида 123456:AA...

2. Gemini

ЖДЁТ

Google AI Studio → API Keys → Copy key. Это строка AQ..., не номер проекта. В модели оставь gemini-3.8-flash. Имя gemini-2.5-flash новым ключам не подходит.

3. Резюме hh

ЖДЁТ

В браузере открой hh.ru/applicant/resumes, кликни резюме и скопируй адресную строку. Нужна ссылка https://hh.ru/resume/...

Конфиг

ЖДЁТ

Кнопка включится только после трёх живых PASS. Мок их не заменяет. Файл не сохраняется в проект, только скачивается.
